# BeeCode goals

This directory is the executable product plan for BeeCode. The complete
year-scale roadmap and target-specific goal documents are being added in the
next planning checkpoint.

Every goal will have:

- a stable identifier;
- an outcome and rationale;
- concrete deliverables;
- measurable acceptance criteria;
- automated or manual evidence;
- dependencies and sequencing;
- risks, mitigations, and explicit non-goals.

Goal status is one of `proposed`, `ready`, `active`, `blocked`, `verified`, or
`retired`. A goal becomes `verified` only when its evidence is linked from the
goal document.
