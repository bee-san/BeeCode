Given a list of integers `nums` and an integer `target`, return the **indices** of
the two numbers that add up to `target`.

Each input has exactly one solution, and you may not use the same element twice.
The order of the two indices in your answer does not matter.

## Constraints

- `2 <= len(nums) <= 10_000`
- `-10^9 <= nums[i] <= 10^9`
- Exactly one valid answer exists.

## Follow-up

The obvious solution checks every pair, which takes O(n²) time. Can you do it in
a single pass?
