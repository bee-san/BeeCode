`jumps[i]` is the furthest you may move forward from index `i`. You start at index `0`.

Return `True` if some sequence of jumps reaches the last index.

## Constraints

- `1 <= len(jumps) <= 10000`
- `0 <= jumps[i] <= 100000`

## Follow-up

You do not need to know *which* jumps to take, only whether the end is reachable — and that is
a much weaker question. One number carried along the array answers it. What number?
