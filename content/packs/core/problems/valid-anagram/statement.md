Given two strings `s` and `t`, return `True` if `t` is an anagram of `s`.

`t` is an anagram of `s` when it uses exactly the same characters the same number of
times, in any order. Two empty strings are anagrams of each other.

Comparison is case-sensitive: `"a"` and `"A"` are different characters.

## Constraints

- `0 <= len(s), len(t) <= 50_000`
- `s` and `t` consist of lowercase and uppercase English letters.

## Follow-up

Sorting both strings and comparing them works. Can you decide the answer in a single
pass over each string, without sorting?
