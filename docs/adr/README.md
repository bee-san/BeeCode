# Architecture decision records

Architecture decision records (ADRs) capture choices that would otherwise be
rediscovered repeatedly.

Each ADR uses this lifecycle:

- **Proposed** — open for validation.
- **Accepted** — the current project rule.
- **Superseded** — replaced by a later ADR.
- **Rejected** — considered and deliberately not chosen.

An ADR should state the context, decision, consequences, alternatives, and the
evidence required to revisit it.
